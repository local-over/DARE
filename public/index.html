The Syntax

DARE is a token-efficient markup language. It compiles directly to native PDFs.

@setup {
    format: a4;
    $main: bold size=20;
}
@doc {
    page {
        txt($main) { Hello World }
    }
}

The Live API

Send DARE code and JSON data. Get a PDF back instantly. No storage, no tracking.

POST /api/render
Content-Type: application/json

{
    "code": "@doc { page { txt { Hello {{ user }} } } }",
    "data": { "user": "Agent" }
}
